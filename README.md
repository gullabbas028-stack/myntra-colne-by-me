# Myntra Clone Project

A simple frontend clone of the Myntra shopping experience built with HTML, CSS, and JavaScript.

## Features

- Responsive homepage
- Product cards with price and discount details
- Category pages for Men, Women, Kids, Home & Living, Beauty, and Studio
- Add-to-bag interaction with local storage
- Shopping bag page
- Static deployment ready for Vercel

## Project Structure

- `Myntraclone/forhtml/` - HTML pages
- `Myntraclone/css/` - Shared stylesheets
- `Myntraclone/scripts/` - Homepage interactivity
- `itme.js/` - Product data and bag logic
- `images/` - Product and banner images

## Run Locally

Open the project using a simple local server, for example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://127.0.0.1:8000/Myntraclone/forhtml/index.html
```

## Deploy on Vercel

This project is configured as a static site and can be deployed directly on Vercel.

### Recommended Vercel settings

- Build Command: `npm run build`
- Output Directory: `.`
